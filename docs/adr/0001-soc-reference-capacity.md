# 0001. SOC는 25 °C C/20 방전용량 하나를 기준으로 정의한다

- 상태: 확정 (2026-11-12)

## 결정

SOC = 1 − (만충 이후 방전 Ah) / Q_ref, Q_ref = 25 °C C/20 방전용량 (Samsung 30T: 3.0326 Ah).
모든 온도에서 같은 Q_ref를 쓰고, EKF의 전류적산 항도 같은 Q_ref를 씁니다.

## 이유

- 같은 SOC가 어느 온도에서나 같은 저장 전하량을 뜻하므로, OCV-SOC 곡선을 온도별로 그대로 비교·보간할 수 있습니다.
- 온도별 1C 용량으로 정규화하면 저온에서 "SOC 0%"가 아직 전하가 남은 상태를 가리키게 되어, OCV 곡선과 EKF 상태방정식이 온도마다 다른 SOC 정의를 쓰게 됩니다.

## 결과

- 저온 주행 시험은 SOC 0%까지 내려가지 않습니다(−20 °C에서 약 22%에서 종료). 저온에서 SOC 하단은 평가 범위 밖입니다.
- 전하량 적분은 우측값(right-hold)으로 합니다. 시험기가 각 샘플에 직전 구간의 전류를 기록하기 때문이며, 이렇게 해야 시험기 Ah 카운터와 일치합니다.
