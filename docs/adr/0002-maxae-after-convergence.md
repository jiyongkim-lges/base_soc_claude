# 0002. MaxAE는 수렴 시점 이후 구간에서 잰다

- 상태: 확정 (2026-11-12)

## 결정

- 초기 SOC 오차는 +5%p와 −5%p 두 경우로 시작합니다.
- 수렴 시점 t_conv = |SOC 오차|가 처음으로 3%p 아래로 내려온 시점. 상한 600 s.
- MaxAE = t ≥ t_conv 구간의 max |SOC_est − SOC_true|. 합격 기준 MaxAE ≤ 3%p, t_conv ≤ 600 s.
- 함께 기록: RMSE, MAE, t_conv, 단자전압 추정 RMSE.

## 이유

초기 오차가 5%p이므로 t = 0부터 재면 어떤 추정기도 3%p를 통과할 수 없습니다.
전류적산만 하는 추정기는 5%p 편향을 그대로 유지해서 t_conv에 도달하지 못하므로, 이 정의로도 전류적산형 해는 걸러집니다.
